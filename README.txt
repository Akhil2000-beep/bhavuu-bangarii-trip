BHAVUU BANGARII TRIP — INTERACTIVE QR SURPRISE

Included:
- index.html — pink loading screen, attached song, animated blue robot-cat/Doraemon-style character, letter reveal, PDF download.
- qr.html — generates a QR for the live website URL and puts a heart in the centre.
- assets/song.mp3 — your attached audio.
- assets/Bhavuu_Bangarii_Trip.pdf — your original 15-page PDF.

IMPORTANT:
A QR scan can only open a website that is publicly reachable. This package therefore generates the final QR from the website's own live URL.

How to publish:
1. Upload the entire folder to a static host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the published /qr.html page.
3. Save/screenshot/print the generated QR.
4. Scan it with another phone. It opens index.html.
5. The song attempts to autoplay. If Chrome blocks autoplay with sound, the page shows a Tap to begin/play button.
6. When the song ends, the character walks forward, presents the letter, and tapping the letter downloads the original PDF.

The PDF is kept unchanged; it is the same 15-page letter you supplied.
